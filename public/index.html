MADE FOR SHARED LISTENING

Everything moves together.

Thoughtful details that keep every listener in the moment.

01

One shared timeline

Play, pause, seek, and track changes update the room state for connected listeners.

02

Collaborative queue

Anyone in the room can add a track; the server advances to the next queued song.

03

Live room presence

A live connection count shows how many listeners are in the room right now.

04

Reconnect and recover

Reconnecting clients request an updated room snapshot to catch up with playback.

05

Persistent conversations

Chat messages are stored in SQLite and history is sent when listeners connect.

06

Managed friend accounts

An administrator can create and manage the accounts used to enter the private room.

07

Listener-aware room timer

The session clock starts with the first non-admin listener and resets when the last one leaves.

08

Admin database reports

Administrators can download SQLite account metadata and chat history as CSV or PDF. Passwords and hashes are excluded.
